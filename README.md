# homebrew-klaatcode

Homebrew tap for [KlaatCode](https://klaatai.vercel.app) — AI coding agent for the terminal.

## Install

```bash
brew tap aakashrajput/klaatcode
brew install klaatcode
```

## Update

```bash
brew upgrade klaatcode
```

## Uninstall

```bash
brew uninstall klaatcode
brew untap aakashrajput/klaatcode
```
